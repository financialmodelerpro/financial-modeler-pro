## Standing invariants (do not regress these)

- **One call path.** `runAi()` is the ONLY place `ANTHROPIC_API_KEY` is read and the only place an SDK client is constructed. It never throws; every outcome is a typed `AiResult`.
- **Registration never clobbers admin intent.** Re-registering refreshes the DEFINITION only; an admin's toggle and edited caps survive every deploy.
- **The cap comes from the database, always.** No enforcement path holds a cap value. Features register DISABLED.
- **Meter before the call, refund on failure.** Consume-after-success would let concurrent requests all pass the check first. Failures give the credit back (mig 206).
- **Availability before money.** A field the model cannot support is refused before the meter, so it costs nothing.
- **No fabrication, checked not just asked.** Grounding supplies labelled facts; `auditGroundedText` classifies every numeric literal in the output as supported / rounded / unsupported.
- **Editable draft, never auto-saved.** Generation writes nothing; applying is a user action, and it still needs Save.
